12// The undoable edits a project supports, in one place.
13//
14// Every method here records one history step and applies it, subject to the
15// origin: a User or Remote edit enters history, while Load, UndoRedo and
16// Internal changes are applied without being recorded. Callers do not open
17// history scopes for a single edit -- that is what this does.
18//
19// Use TimelineFacade for reading the document and for changes that are not
20// user edits; use this for anything a user could undo.

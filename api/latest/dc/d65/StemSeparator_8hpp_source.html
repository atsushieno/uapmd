49// A stem separation backend. Implementations are contributed by addins through
50// the `/uapmd/audio-import/stem-separator/v1` extension point; the registry
51// only borrows them, so an addin must remove its separator during cleanup().

53// separate() runs on a worker thread and must honor the request's cancellation
54// callbacks. It is never called on the audio thread.

65// Separators are contributed, not replaced: an addin adds its own backend
66// alongside whatever else is registered. Registration order is preserved so

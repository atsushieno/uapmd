Detailed Description

UapmdJSRuntime encapsulates the QuickJS runtime and provides a clean API for registering UAPMD-specific JavaScript functions. This class is decoupled from GUI components and can be used in any context that needs JavaScript execution with UAPMD APIs.

◆ evaluateScript()

std::string uapmd_app::UapmdJSRuntime::evaluateScript ( const std::string &  code,
std::function< std::optional< std::string >(std::string_view)>  fallbackModuleResolver = {} 
)

Evaluates code. If it contains "import", runs it as an ES module via runModule, resolving imports against the embedded AppJsLib bundle first; fallbackModuleResolver (if provided) is tried when a module isn't found there. Otherwise evaluates it as a plain expression. Returns the JSON string of the result, or "undefined". Throws on error.

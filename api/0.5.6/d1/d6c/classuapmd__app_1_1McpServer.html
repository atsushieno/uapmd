Detailed Description

MCP (Model Context Protocol) transport layer.

Two modes: Server mode — embeds an HTTP/JSON-RPC server on localhost (desktop only). Constructed with McpServer(int port). Client mode — opens an outbound WebSocket connection to an external relay. Constructed with McpServer(std::string relayUrl, bool autoReconnect).

In both modes, incoming JSON-RPC requests are queued and dispatched on the main thread by calling processMainThreadQueue() from the render loop each frame.
